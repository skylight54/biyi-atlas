# 01 · 常驻小地图与显示偏好

> 请完成 01 HUD 卡，在分配给 01 的独立目录实现免持物小地图、旧入口退役和可复用的个人设置面板。向 02、03 交设置面板入口，向总控交事件接线及测试结果。

[共同契约与文件归属](开发契约.md) · [跨分支接口](接口约定.md)

**开工条件。** 依赖 00。与 02、03 并行。

## 实施与交接

1. 沿用 AtlasHud 的 Forge overlay 接口，保留追踪和道路记录反馈；处理右上角互相遮挡。实现右上默认、四角可移、北向/随人、已知标记、0.5–3× 限幅和本机持久化。出区后继续跟人并以云墨遮住区外，地图边界不修改倍率。
2. 收起旧手持渲染与 Shift＋右键设置、创造栏与获取路径。旧 atlas 物品 ID 可加载、无主动地图行为；维护许可证。把 ClientEvents、命令等集中接线需求交总控/05。已有 heldZoom 有意义时映射到合法范围，没有值时默认 1×。
3. 交独立设置面板，02 和 03 从同一入口打开。全屏与 F1 时隐藏 HUD；普通游戏滚轮继续选择快捷栏。复用合法瓦片缓存，移动按帧更新指针，底图随数据或镜头变化更新。

## 本卡验收

空手和双手持其他物品均出现 HUD，旧地图堆栈重进后可读取。选左下、1.5×，出区再回来、调整大图缩放、重登，位置和倍率仍正确；无地图权时只显示合法云墨。录一组 HUD 开/关帧时对比。
