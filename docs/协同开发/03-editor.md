# 03 · 作者工作台与对象编辑

> 请完成 03 作者工作台卡。把区域树、对象属性、画布工具、权限设置和玩家预览组织进新的作者界面，通过约定适配已有编辑操作。

[共同契约与文件归属](开发契约.md) · [跨分支接口](接口约定.md)

**开工条件。** 依赖 00。先接旧数据，后续消费 04/05/06/07/08 的状态与专用面板。

## 实施与交接

1. 建立区域树与按对象出现的属性；区分大区、子区、地标、作者路标、道路。统一画区入口；改父区检查同维度、包含与循环，列出受影响内容。编辑顶点、确认、取消、撤销和重做要能从画布完成，页脚随真实工具变化。
2. 左上设置复用 01 的个人偏好，增加服务端能力和 MCP 状态。接入真假有别的采集进度、候选校对、局部楼层与发布回执。无对应服务时显示原因。状态由提供方产生，界面不写第二份“已发布”状态。
3. 提供玩家预览、退出预览及脏草稿返回路径。维护旧地标/道路的放置、删除与撤回；区分共享地标与玩家私人路标。将各工作区面板扩展位置交功能负责人。

## 本卡验收

创造且授权才进入；浏览时没有“正在画顶点”提示。可新建大区、子区、道路，取消一次草稿、撤销一次删除、预览并返回，镜头与选区保留。服务端撤权后停止提交，未提交改动可恢复。
