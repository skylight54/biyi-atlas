# 04 · 原生实景与增量采样

> 请完成 04 原生采样卡，让没有 JourneyMap、没有已画区域的新工程也能看到方块实景，圈定区域后可分批生成。将任务与瓦片交给 03、05，并把双表面样本交给 06、08。

[共同契约与文件归属](开发契约.md) · [跨分支接口](接口约定.md)

**开工条件。** 依赖 00。与 05 对同一夹具并行开发。

## 实施与交接

1. 复用 SurfaceSurvey、TerrainSurvey 与现有瓦片。地表实景展示顶面颜色、树冠、水面和高度，保留现有保底地形语义；框选临时矩形即可采样。对外提供未知覆盖与只读顶面/地面快照，支持 08 后续请求局部切片。旧调查数据能继续画底图。
2. 按预算在游戏线程取样、后台编码。默认只读已生成区块，扩展生成是显式操作。支持部分返回、取消、继续、重试和缓存上限；可见区域优先，相邻瓦片有一致边界。向 05 交付进度与草稿瓦片，由 05 发布。
3. 给 03 实景读取接入点；JourneyMap 的旧参考开关和原生默认显示由总控接到工作台。记录低清首屏、密集移镜时帧时、采样时服务端 tick 与区块生成变化。

## 本卡验收

无 JourneyMap 及历史瓦片的副本可从空白工程圈区，任务未完成时作者已能看部分瓦片。负坐标、跨区边界和两个缩放级别无明显缝。取消时旧发布仍可用，默认采样不扩展新地形。
