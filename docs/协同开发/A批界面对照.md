# A 批界面对照 · 2026-11-28

## 旅行图底片

首次工作台截图显示开关已开、选择 day，位置在负坐标。此时当前世界的 day 文件夹仅有远处的正坐标切片。原实现在文件缺失时直接跳过。修复后，作者打开 day 参考会先绘制玩家附近 256 × 256 方块内已加载区块的地表颜色，再叠加当前图层已有的 JourneyMap 切片。其他切层保持原本含义。原生参考只用于编辑画布，不写入区域底图。

部署修复后，同一发行版的工作台实机截图可见林地、水岸与建筑轮廓。此时 JourneyMap 也新增了负坐标 day 切片，因此这次截图验证了混合显示；纯原生缺片路径、建筑一对一对齐和独立玩家收图仍待分别验收。
