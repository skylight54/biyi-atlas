### 对齐和失效规则

- 世界坐标使用方块单位，+X 向东、+Z 向南，北朝上的图像原点在左上。区域边界保留原精度。瓦片索引用向下取整，包含左/上边，排除右/下边；采样在像素中心，邻块余边仅供绘制。用负坐标、跨原点和相邻瓦片边线做公共用例。旧候选的仿射映射方向沿用现有 manifest。
- 断线、切世界、角色降权、范围版本变化均失效相应请求与缓存；作者权限未知时只消费玩家数据。切换图面保留镜头；快速 A→B 再收到 A 的回包只能更新仍有效的 A 缓存。
- 发布前检查起始版本。对同一操作 ID 的重试返回同一结果；重启后可通过目标版本或持久记录确认是否已提交。边界修改与采样发生竞争时，停止使用旧指纹的瓦片。删除及撤销沿用稳定对象 ID，通过服务端版本区分合法恢复和旧快照回写。
- 工程包新增内容带格式版本与校验，读取旧整数层、旧美化候选与原配准。旧数据没有楼层定义时沿用旧地图视图；区域数据缺失时客户端保留可见状态和重试入口。05 单点分配网络消息及版本，07 单点演进 MCP 工具输入输出。

### 00 交给并行分支的最小样例

使用隔离夹具模拟一个可见大区、一个锁定子区、一处带入口地标、地表和一张底图瓦片。给出玩家/作者两种读取结果、正负坐标往返、保存成功和起始版本冲突各一个例子。初期没有局部层或美化候选时返回“仅地表”和“使用底图”。夹具只供测试。首批正常入口可以接旧存储；未接入的写入和发布在工作台显示不可用原因。
